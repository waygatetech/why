Copy vet's `.goreleaser.yaml` (linux/darwin, amd64/arm64, CGO off, tar.gz, checksums.txt), with one difference: ldflags are just `-s -w`. `why` has no `main.version` vars. Go 1.24+ stamps the git tag into `debug.ReadBuildInfo().Main.Version`, and goreleaser builds from the tagged checkout, so `why --version` already reports the release tag.

`.gitignore` gets `dist/`. Without it, goreleaser's output dir makes the tree dirty and the stamped version comes out as `vX.Y.Z+dirty`.

Verify: tagged `goreleaser release --skip=publish,announce` in a scratch copy (this repo has no remote yet, so `goreleaser check` fails here), then run the built binary with `--version`.
