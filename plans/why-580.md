Ruling (Brian, 2026-10-08, via tix approve): receipts in the git common dir.

- `internal/decision`: provenance constants (`Human`, `AgentApproved`, `Agent`), `IsHuman`; Parse/Marshal reject unknown decided_by.
- `internal/provenance`:
  - `Confirm(tty io.ReadWriter, ds) (bool, error)`: lists the decisions, asks `[y/N]`.
  - `AddReceipt(gitDir, path)` / receipts lookup (sha256 of file bytes).
  - `Check(ctx, root, base) ([]string, error)`: merge-base via git; for each `decisions/*.md` in the working tree, if present at merge base, fail when decided_by or ruling differ; if new, fail when human provenance lacks a matching receipt.
- `record.go`: if any decision to write has human provenance, open /dev/tty. Open fails => downgrade all to `agent`, warn on stderr. Declined => error, nothing written. Confirmed => write, then add receipts.
- `check.go`: `why check [--base main]` prints violations, returns error if any.
- Tests: decided_by validation; Check table (edited ruling, edited decided_by, new human w/o receipt, new human with receipt, new agent, untouched) in a temp git repo; cli test that `--decided-by human` without a TTY writes `agent`.
