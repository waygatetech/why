Ruling (Brian, 2026-10-08, via tix approve): plan entries carry supersedes; hook unchanged.

- `internal/plan`: `Entry.Supersedes`; `fromPlanFile` copies it.
- `internal/decision`: `Chain(ds, id) (older, newer []Decision)`, transitive and cycle-safe.
- `list.go`: `--all` skips `Active`.
- `show.go`: `why show <id>` prints the decision file, then `supersedes:` and `superseded by:` lines.
- `record.go`: `--supersedes` flag (stdin fills it if the flag is empty); fail on unknown ids.
- `provenance.Check`: second pass over the parsed decisions; any non-human decision superseding a human one is a violation.
- Tests: Check table cases (agent supersedes human: fail; human with receipt supersedes human: pass; agent supersedes agent: pass), Chain, and CLI cases for list --all and show.
